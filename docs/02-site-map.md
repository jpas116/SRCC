# Proposed site map

| Page | Purpose | Status in mockup |
|---|---|---|
| **Home** | Hero, "This week at SRCC" (from Zeffy), program teasers, membership hook (0% commission), Instagram feed, Book the Space banner, Donate and newsletter in the footer. | Done |
| **Events** | Tuesday regulars banner, upcoming events with working filters, ticket buttons, searchable archive of past shows. | Done |
| **Single event** | Flyer, lineup, details, embedded Zeffy ticket panel, "more this month". | Done (uses Big Blitz as sample) |
| **Programs** | A card per program with when / cost / who it's for. Studios and gear section. "Pitch a program" call to action. | Done |
| **About** | Mission, key numbers, founders' story, team, ways to get involved, sponsors. | Done, needs real photos and copy |
| **Membership** | Perks, selectable tiers, Zeffy signup, FAQ. | Done, needs prices and tier names |
| **Book the Space** | Pick what you're planning, inquiry form, venue specs, address. | Done, needs venue specs |

## Design direction

- **River:** deep river-teal background built from SRCC's existing `#2d6f65`, flowing contour lines in heroes, wavy section dividers.
- **Conspiracy:** taped-up flyers, Polaroid-style photo stacks, stickers, a scrolling marquee. Gig-poster and zine energy.
- **Events as ticket stubs** with perforated edges.
- **Fonts:** Dela Gothic One (headlines), Instrument Sans (body), IBM Plex Mono (labels).
- **Palette:** river teal `#0e2421` / `#2d6f65`, cream `#efe9da`, riso pink `#ff5a7e` (accent), riso yellow `#f2d43a`.

## Content SRCC still needs to provide

- Membership tiers and monthly prices
- Founders' story in their own words, and a quote
- Team names, roles and portraits
- Photos of the building, the stage, the lounge and crowds at shows
- Venue specs: capacity, stage size, PA, load-in
- Sponsor logos
- FAQ answers on the Membership page
- Confirm recurring dates: Boundaries Lounge Jams (second Sundays?) and Yoga Flow (third Sundays?)

## Other features recommended

- Hidden structured data on each event page so shows appear in Google's event results
- A simple admin page so volunteers can update programs and photos without code
- Newsletter and volunteer signup forms
- One donation platform (Zeffy) instead of PayPal plus Zeffy
