# Design mockup source

These are the source files for the seven-page mockup. They are design-canvas files, which means:

- Each `.dc.html` file is one page of the mockup.
- `canvas.json` is the index: page names, sizes and layout on the canvas.
- They only render inside the design canvas, not as a standalone website. The live mockup is at https://claude.ai/artifact/Q4k5GHS2Ug6rYHJFdxJDx7.
- Image references point at `../assets/images/web/`.

When the design is approved, these files are the reference for building the real site. The real site code will live in its own folder in this repo.

| File | Page |
|---|---|
| `Main.dc.html` | Home |
| `Events.dc.html` | Events list + archive |
| `EventDetail.dc.html` | Single event with Zeffy tickets |
| `Programs.dc.html` | Programs & resources |
| `About.dc.html` | About |
| `Membership.dc.html` | Membership |
| `Book.dc.html` | Book the Space |
